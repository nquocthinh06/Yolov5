───────────────────────────────────────────────────────────────────────────
⌨️  COMMAND LINE USAGE
───────────────────────────────────────────────────────────────────────────

Detection:
  python detect.py --source image.jpg --weights yolov5s.pt --conf 0.5
  python detect.py --source video.mp4 --weights yolov5s.pt
  python detect.py --source 0 --weights yolov5s.pt  # Webcam

Training:
  python train_custom.py --data data/traffic_signs_vietnam.yaml --epochs 100

Validation:
  python val.py --weights best.pt --data data/traffic_signs_vietnam.yaml

Export:
  python export.py --weights best.pt --include onnx

GUI:
  python scripts/gui_inference.py

🐛 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────

Port 8501 already in use:
  streamlit run app_web.py --server.port 8502

Module not found (streamlit, torch, etc):
  pip install <module_name>

Slow performance:
  - Reduce batch size
  - Reduce image size
  - Enable GPU if available
  - Close other applications

File upload not working:
  - Check file format (JPG, PNG, MP4)
  - Ensure file < 200MB
  - Verify file is not corrupted

🎯 COMMON TASKS
───────────────────────────────────────────────────────────────────────────

Detect in image:
  1. Open web app: streamlit run app_web.py
  2. Go to "Detect & Surveillance" tab
  3. Upload image
  4. Click "Run Detection"

Train custom model:
  1. Prepare dataset in YOLO format
  2. Create YAML config file
  3. Open web app
  4. Go to "Train Model" tab
  5. Upload YAML file
  6. Click "Start Training"

Export model:
  1. Open web app
  2. Go to "Export Model" tab
  3. Upload .pt weights
  4. Select formats (ONNX, TensorRT, etc)
  5. Click "Export Model"
