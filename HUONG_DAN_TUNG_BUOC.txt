HUONG DAN PUSH CODE LEN GITHUB - TONGUE BUOC MOT (Tieng Viet Khong Dau)

BAN CO THE CHAY TONGUE LENH NAY TRONG POWERSHELL:

=== BUOC 1: REFRESH PATH (De su dung git) ===
Sao chep va paste lenh nay vao PowerShell:

$env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path","User")

Sau do nhan Enter. Khong co output la binh thuong.


=== BUOC 2: KIEM TRA GIT ===
$env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path","User")
git --version

Ket qua: Phai hien thi "git version 2.51.2.windows.1"


=== BUOC 3: TAO REPOSITORY TREN GITHUB ===
1. Mo: https://github.com/new
2. Dien thong tin:
   - Repository name: yolov5-traffic-detection (hoac ten khac tuy thich)
   - Description: YOLOv5 Traffic Sign Detection (tuy chon)
   - Public hoac Private (chon Public de chia se)
3. KHONG CO TIC CHON "Initialize this repository with a README"
4. Click "Create repository"

COPY DUONG DAN REPOSITORY TREN GITHUB, co dang:
https://github.com/YOUR_USERNAME/yolov5-traffic-detection.git


=== BUOC 4: KHOI TAO GIT TRONG THU MUC HIEN TAI ===
Trong PowerShell, chay lenh:

git init

Ket qua: "Initialized empty Git repository in C:\Users\Thinh Nguyen\Downloads\yolov5-master\yolov5-master\.git"


=== BUOC 5: THEM TAT CA FILES ===
git add .

Khong co output la binh thuong (co nghia la thanh cong).


=== BUOC 6: TAO COMMIT ===
git commit -m "Initial commit: YOLOv5 traffic detection project"

Ket qua: Se hien thi so files da commit.


=== BUOC 7: DOI TEN NHANH THANH MAIN ===
git branch -M main

Khong co output la binh thuong.


=== BUOC 8: THEM REMOTE REPOSITORY ===
Thay YOUR_USERNAME bang username GitHub cua ban, roi chay:

git remote add origin https://github.com/YOUR_USERNAME/yolov5-traffic-detection.git

Ket qua: Khong co output la thanh cong.


=== BUOC 9: PUSH CODE LEN GITHUB ===
git push -u origin main

Tren lan dau, se hoi:
- Nhap username GitHub cua ban
- Dieu quan trong: KHONG dung password! Dung Personal Access Token (PAT)

De tao PAT:
1. Vao: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Dat ten token: "yolov5-push"
4. Chon quy?n: tick chon "repo" (full control of private repositories)
5. Click "Generate token"
6. COPY token (chu y: chi hien chi 1 lan, sau do phai luu lai)

Sau do, dung token nay khi PowerShell hoi password.


=== KIEM TRA KET QUA ===
Sau khi push thanh cong, go to: https://github.com/YOUR_USERNAME/yolov5-traffic-detection

Phai thay tren GitHub cac files cua duan.


=== TOM TAT - LENH CAN CHAY ===
1. $env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path","User")
2. git init
3. git add .
4. git commit -m "Initial commit: YOLOv5 traffic detection project"
5. git branch -M main
6. git remote add origin https://github.com/YOUR_USERNAME/yolov5-traffic-detection.git
7. git push -u origin main

Sau buoc 7, nhap username va dung PAT (khong phai password).
